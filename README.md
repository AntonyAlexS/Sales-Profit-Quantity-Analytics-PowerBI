# 📊 Sales-Profit-Quantity-Analytics (PowerBI)


## 🔍 Project Overview

This project showcases a **dynamic and interactive Sales,profit,Quantity Analytics Dashboard** developed using **Power BI**. The dashboard provides a unified view of **Sales, Profit, and Quantity** performance with advanced **time intelligence (CY, PY, YoY)** and **field parameter–driven metric switching**.

The solution is designed to support **business decision-making** by enabling users to seamlessly switch metrics, analyze regional trends, and compare year-over-year performance through a clean, executive-ready layout.

---

## 🎯 Business Objectives

* Analyze **Sales, Profit, and Quantity** in a single unified dashboard
* Compare **Current Year (CY)** vs **Previous Year (PY)** performance
* Track **Year-over-Year (YoY) growth** dynamically
* Enable **metric-driven analysis** using Field Parameters
* Provide **region-wise and state-wise insights**

---

## 🚀 Key Features

### 🔁 Dynamic Metric Switching

* Implemented **Power BI Field Parameters** to switch between:

  * Sales
  * Profit
  * Quantity
* All visuals (KPIs, charts, map, tables) update automatically based on selected metric

### 📆 Advanced Time Intelligence

* Current Year (CY) metrics
* Previous Year (PY) metrics
* YoY % growth calculations
* Handles edge cases (first year with no PY data)

### 🌍 Geographic Insights

* Interactive **Map visual** showing performance by **State & Region**
* Helps identify high-performing and underperforming locations

### 📊 Regional Overview Cards

* Central, East, South, and West regions
* Monthly trend analysis with PY reference
* KPI-style presentation for quick insights

### 📋 CY vs PY Comparison Table

* Side-by-side comparison of CY and PY metrics
* YoY % indicators with conditional formatting
* Region-level performance comparison
  

## 📂 Dashboard Highlights

* Sales / Profit / Quantity Overview Dashboard
* Dynamic CY vs PY comparison
* YoY Growth analysis
* Region & State-level insights
